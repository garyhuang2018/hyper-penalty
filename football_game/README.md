# 热血足球 - 调试与运行指南

## 运行方法

### 1. 启动本地服务器

**必须使用 HTTP 服务器**，禁止直接双击 `index.html`。

ES6 模块 (`import`/`export`) 出于安全限制，不能通过 `file://` 协议加载。

```bash
cd D:/13_develop/football_game
python -m http.server 8080
```

然后浏览器访问: `http://localhost:8080`

---

## 调试步骤

### 按任意键无法开始游戏？

1. **检查服务器是否启动**
   ```bash
   curl http://localhost:8080/
   # 应返回 200
   ```

2. **检查浏览器控制台 (F12)**
   - 是否有 CORS 错误？
   - 是否有模块加载失败 (Failed to load module)？

3. **如果控制台报错 "CORS" 或 "file://"**
   - 说明你直接双击打开了 index.html
   - 必须用 `http://localhost:8080` 访问

---

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 看不到开始界面 | 直接双击 index.html | 用 http://localhost:8080 访问 |
| 按键无反应 | 同上 | 同上 |
| 模块加载失败 | CORS 安全限制 | 必须启动 HTTP 服务器 |
