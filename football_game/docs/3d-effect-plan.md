# 球员立体效果方案

## 一、问题分析

### 当前渲染方式
- 使用纯色矩形 (`fillRect`) 绘制各部位
- 无渐变、无阴影、无高光
- 整体呈"扁平纸片人"效果

### 目标效果
- 从俯视角模拟3D立体感
- 球员看起来有"厚度"和"重量感"
- 与热血足球原版的像素风格保持一致

---

## 二、方案论证

### 方案A: 渐变 shading（推荐）

**原理**：为每个身体部位添加从上到下的线性渐变，模拟光线照射效果。

```
原版:        方案A渐变:
┌────┐      ┌────┐  ← 高光(白)
│████│      │▓▓▓▓│  ← 亮面(球队色+亮)
│████│  →   │████│  ← 中间(球队色)
└────┘      │▒▒▒▒│  ← 暗面(球队色+暗)
            └────┘  ← 阴影(深色)
```

**优点**：
- 实现简单，效果明显
- 保持像素风格
- 性能消耗小

**缺点**：
- 需要为每个部位单独计算渐变
- 需要定义光源方向（统一从上方照射）

**实现方式**：
```javascript
// 为身体添加渐变
const gradient = ctx.createLinearGradient(0, -14, 0, -4);
gradient.addColorStop(0, lighten(teamColor, 30));  // 高光
gradient.addColorStop(0.3, teamColor);              // 正常
gradient.addColorStop(1, darken(teamColor, 30));    // 阴影
ctx.fillStyle = gradient;
ctx.fillRect(-5, -14, 10, 10);
```

### 方案B: 投影阴影

**原理**：在球员下方绘制一个半透明的椭圆作为阴影。

```
      ┌─────┐
      │  ●  │  ← 球员
      └─────┘
        ╭──╮
        │▒▒▒│  ← 阴影
        ╰──╯
```

**优点**：
- 增强"站立感"
- 视觉上更有重量感

**缺点**：
- 阴影大小需要根据跳起高度变化
- 可能影响球员重叠时的辨识度

**实现方式**：
```javascript
// 绘制阴影（在身体下方）
ctx.fillStyle = 'rgba(0, 0, 0, 0.3)';
ctx.beginPath();
ctx.ellipse(x, y + 12, 12, 4, 0, 0, Math.PI * 2);
ctx.fill();
```

---

### 方案C: 轮廓线+高光

**原理**：在身体边缘添加高光线，模拟光线反射。

```
原版:        方案C:
┌────┐      ┌────┐
│████│      │▓▓▓▓│
│████│  →   │█░░█│  ← 轮廓线
│████│      │▒▒▒▒│
└────┘      └────┘
```

**优点**：
- 立体感强
- 可区分不同球员

**缺点**：
- 实现复杂（每个部位都要加轮廓）
- 可能显得"脏"

---

### 方案D: 像素风格伪3D（推荐）

**原理**：利用像素风格的特点，通过颜色深浅和排布模拟立体感。

```
原版:        方案D:
■■■■■■      ■■■■■■
■■■■■■  →  ■■■■■■
■■■■■■      ■■■■■■  (添加阴影列)
```

**优点**：
- 完美契合像素风格
- 性能好

**缺点**：
- 立体感有限

---

## 三、推荐方案：A + B 组合

### 核心策略

1. **渐变 shading（A方案）**：为主色部位（身体、头发）添加从上到下的渐变
2. **投影阴影（B方案）**：在球员下方添加椭圆阴影

### 详细设计

#### 1. 光源设定
- **方向**：统一从上方（Y轴负方向）照射
- **高光**：部位顶部 20%
- **中间**：部位中部 60%
- **阴影**：部位底部 20%

#### 2. 颜色计算
```javascript
// 辅助函数
function lighten(hex, percent) {
  // 将颜色变亮
}

function darken(hex, percent) {
  // 将颜色变暗
}
```

#### 3. 各部位处理

| 部位 | 处理方式 |
|------|----------|
| 头发 | 纯色+底部阴影 |
| 头部 | 皮肤色渐变(亮→暗) |
| 身体 | 球队色渐变(亮→暗) |
| 手臂 | 皮肤色渐变(亮→暗) |
| 腿 | 深色(已暗，跳过渐变) |

#### 4. 阴影绘制
```javascript
// 阴影（球员正下方）
ctx.fillStyle = 'rgba(0, 0, 0, 0.25)';
ctx.beginPath();
ctx.ellipse(x, y + 15, playerRadius * 0.8, 4, 0, 0, Math.PI * 2);
ctx.fill();

// 跳起时阴影缩小并上移
if (player.isJumping) {
  const jumpHeight = player.jumpHeight;
  ctx.beginPath();
  ctx.ellipse(x, y + 15 + jumpHeight, playerRadius * (0.8 - jumpHeight/100), 4, 0, 0, Math.PI * 2);
  ctx.fill();
}
```

- 头部：渐变

### 验收标准
- 球员身体有明显的明暗变化
- 球员下方有阴影
- 跳起时阴影缩小/上移
- 保持像素风格

## 六、风险评估

| 风险 | 影响 | 缓解 |
|------|------|------|
| 渐变导致像素风格丢失 | 高 | 控制渐变步数，保持像素感 |
| 阴影影响性能 | 低 | 使用简单椭圆，不使用图片 |
| 跳起高度阴影计算复杂 | 中 | 使用简化公式 |
