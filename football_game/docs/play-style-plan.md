# 热血足球 - PC版操作改造计划

## 一、PC按键映射

| 原版(FC/SFC) | 原版功能 | PC按键 | 说明 |
|--------------|----------|--------|------|
| 方向键 | 移动/过人 | WASD 或 方向键 | 8方向移动 |
| A键 | 传球/铲球 | J | 带球时传球，无球时铲球 |
| B键 | 射门/撞人 | K | 带球时射门，无球时撞人 |
| A+B | 跳/挑球 | Space | 跳起+挑球过顶 |
| 前+A/B | 头撞/鱼跃 | Ctrl+方向+J/K | 扑救/特殊射门 |
| Shift | 加速 | Shift | 加速跑 |

### 备用方案（简化版）

| PC按键 | 功能 |
|--------|------|
| WASD | 移动 |
| J | 传球(带球)/铲球(无球) |
| K | 射门(带球)/撞人(无球) |
| Space | 跳起+挑球 |
| Shift | 加速 |
| Q/E | 切换控制球员 |

## 二、功能优先级

### P0 - 核心基础（必须实现）

| 功能 | 描述 |
|------|------|
| **传球** | 按J传球给队友，球飞向目标方向 |
| **射门** | 按K射门，球飞向对方球门方向 |
| **铲球** | 按J铲球，抢断对方脚下球 |
| **撞人** | 按K撞人，击倒对方球员 |

| **加速跑** | 按Shift加速移动 |

| 功能 | 描述 |
|------|------|
| **过人** | 上上/下下/左右 连续按触发变向过人 |
| **头撞** | 奔跑中按前+K，头顶球+撞人 |
| **守门员扑救** | 守门员按方向+J/K扑球/打飞 |

| **抢断后触电免疫** | 挑球过顶的球不受必杀技影响 |

### P2 - 高级技巧（可选实现）

| 功能 | 描述 |
|------|------|

| **倒钩** | 后+B 倒钩射门 |
| **鱼跃头球** | 跳起+前+B 鱼跃头球 |
| **吊射** | 传球键(A)射门，吊射难扑 |
| **门将无敌扑救** | 连续按AB 门将无敌扑救 |

## 五、具体功能设计

### 5.1 传球 (J键)

```
触发条件：带球时按J
效果：球以中速飞向队友方向
目标：距离最近的队友 或 面向方向的队友
动画：腿部踢球动作
音效：短促的传球音
```

### 5.2 射门 (K键)

```
触发条件：带球时按K
效果：球飞向对方球门
蓄力：按住时间越长，力量越大
动画：射门腿摆动
音效：射门音
```

### 5.3 铲球 (J键 - 无球)

```
触发条件：无球时按J靠近对方球员
效果：
  - 成功：抢断球，对方倒地
  - 失败：自己可能倒地
动画：铲球动作
成功率：70%（可调整）
```

### 5.4 撞人 (K键 - 无球)

```
触发条件：无球时按K靠近对方球员
效果：双方可能都倒地
动画：身体冲撞
冷却：1秒
```

### 5.5 跳起/挑球 (Space)

```
触发条件：按Space
带球时效果：挑球过顶，球弹起
无球时效果：跳起躲避/抢球
空中时间：0.5秒
冷却：1秒
```

### 5.6 加速 (Shift)

```
触发条件：按住Shift
效果：移动速度 × 1.5
体力消耗：每次加速消耗体力
体力耗尽：无法加速
```

### 5.7 过人

```
触发：上上/下下/左右 快速连按2次同方向
效果：快速变向突破
动画：身体晃动+变向
成功率：80%
```

### 5.8 必杀技

```
触发条件：
1. 带球跳起(K) - 高跳后射门
2. 带球11步后射门 - 自动触发必杀
3. AB同时按 - 倒勾射门

效果：
- 球速大幅提升
- 球带火焰/电击特效
- 守门员难以扑救
- 可能打哭守门员（特效）
```

## 六、守门员特殊操作

### 普通扑救

```
触发：守门员时按方向+J
效果：向方向扑球
成功：抓住球
失败：球被打飞
```

### 强力扑救

```
触发：连续按AB
效果：无敌扑救
条件：球在空中时
成功率：90%
失败：扑出界
```
