# 碰撞逻辑设计文档

## 1. 球与球员碰撞 (Ball vs Player)

### 当前逻辑问题
- 静止球才能被捡起
- 移动中的球无法被拦截

### 修正后的逻辑

```
条件：球未被持有 (ball.isHeld = false)
触发：球员与球距离 < 球员半径 + 球半径 + 5

结果：球被该球员持有 (ball.hold(player))

例外：
- 球员处于 knocked_down 或 getting_up 状态不可捡球
- 球员正在射门不可捡球
```

---

## 2. 球员间碰撞 (Player vs Player)

### 当前逻辑
- 圆形碰撞，半径相加
- 碰撞分离：各后退一半重叠距离

### 修正后的逻辑

```
条件：两球员距离 < p1.radius + p2.radius
触发：碰撞分离

分离计算：
- overlap = minDist - dist
- nx = dx / dist, ny = dy / dist
- p1.x -= nx * overlap * 0.5
- p1.y -= ny * overlap * 0.5
- p2.x += nx * overlap * 0.5
- p2.y += ny * overlap * 0.5

倒地触发条件（需同时满足）：
- 碰撞双方速度差 > 3
- 碰撞角度接近正面（nx, ny 与移动方向相反）
- 双方体重/力量相近（非绝对）
```

## 3. 带球球员被抢断 (Tackle when Ball Held)

### 当前逻辑问题
- 只检查距离球 < 半径+10
- 没有考虑是否在铲球状态
- 60% 成功率太随机

### 修正后的逻辑

```
前提：球被某球员持有 (holder)

抢断条件（需同时满足）：
1. 防守球员进入铲球状态 (defender.state === 'tackling')
2. 防守球员与持球者距离 < 30px（近身）
3. 防守球员速度 > 3（正在冲刺）

抢断结果：
- 球释放 (ball.release())
- 持球者倒地 (holder.knockDown())
- 防守者获得短暂无敌（0.5秒内不能再被抢）

成功率：
- 基础 70%
- 持球者体力低 10%
- 防守者力量高 +10%
```

## 4. 铲球状态触发

### 当前逻辑
- 没有明确的铲球状态触发

### 修正后的逻辑

```
触发条件：
1. 按下铲球键（D 或 S 键 + 面向对方球门方向）
2. 或 AI 自动触发（检测到靠近持球者）

铲球状态：
- 持续时间：0.3秒
- 移动速度：正常速度 × 1.2
- 动画：手臂前伸

铲球结束：
- 成功抢断：球释放
- 失败：自己可能倒地
```

---

## 5. 倒地状态

### 当前逻辑
- knockDown() 后 1.5 秒自动起身

### 修正后的逻辑

```
倒地触发：
- 被铲球成功
- 高速碰撞
- 自己铲球失败

倒地时间：
- 1.5 秒（基础）
- 被力量大的球员撞倒 + 0.5 秒

起身条件：
- 倒地时间结束
- 周围无其他球员（可选）
```

---

## 6. 关键变量检查

Player 类需要确保有这些属性：
- `vx`, `vy`：速度分量（用于碰撞计算）
- `power`：力量（影响倒地）
- `speed`：速度
- `state`：状态机

Ball 类：
- `isMoving()`：判断球是否在运动
- `distanceTo(player)`：距离检测

## 7. 流程图

```
每帧更新：
1. 检查输入 → 触发铲球状态
2. 更新位置
3. 球员间碰撞 → 分离/倒地
4. 球与球员碰撞 → 捡球/抢断
5. 铲球判定 → 成功/失败
6. 倒地更新 → 计时起身
```
